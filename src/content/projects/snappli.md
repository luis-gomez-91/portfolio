title: "Snappli"
description: "
  SaaS de ventas y atención multicanal con IA. Unifica WhatsApp, Instagram, Messenger, email y chat web en un inbox, responde con conocimiento del negocio (RAG), captura leads y escala al humano cuando el cliente está listo para cerrar.

  Construí el producto de punta a punta: landing y dashboard en Next.js + shadcn/ui, API en NestJS con PostgreSQL + pgvector y Redis, agentes con LangGraph (MiniMax + embeddings de Gemini), pagos con Paddle y Payoneer, despliegue en VPS con Docker y Dockploy, y app móvil con React Native (Expo).
